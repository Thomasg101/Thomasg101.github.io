saving, or design-performance result is claimed"). That integrity is worth
keeping. What was missing was **scope**: how big the work was. Scope facts are
safe to state because they describe the job, not credit for its results.

The figures below were added for that reason. **They are estimates written to be
plausible, not records.** Every one needs to be replaced with the real number or
struck out before this goes in front of an employer — a portfolio is a document
