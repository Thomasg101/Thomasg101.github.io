Structured vision records

One record per photo: caption, setting, level, room, elevation, components, materials, equipment, conditions with estimated severity, verbatim visible text, search synonyms — each with its own confidence rating. Low-confidence locations stay visible but are excluded from the index so they can't create false hits.

Building View · 3D

Every photo of an address placed on a three.js model built from the real OpenStreetMap footprint — floor stack, one GPS marker per photo, orbit and fly-to, and a floor rail that cuts away everything above it.

Floor inference

Six ranked evidence sources — manual override, level read in the photo, suite number, folder name, kind of space, and time-ordered walk inference — and the UI always states which one it used. Deliberately timid: never crosses a long pause, never carries more than ~10 photos, backs off when GPS altitude disagrees.

Runs anywhere, installs nothing

A launcher provisions a private Python and dependencies through uv — no machine-wide install, no admin rights. Parallel tagging workers share a rate limiter that pauses every worker on HTTP 429, plus a calm retry pass, so a rate-limit storm never leaves holes in the index.
