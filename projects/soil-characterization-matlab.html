Soil Characterization in MATLAB

A compact geotechnical workflow connecting liquid-limit regression in MATLAB with sieve-analysis bookkeeping in a laboratory spreadsheet.

01 / Context

Turning laboratory readings into interpretable soil behaviour.

The lab record contained two related analyses: blow-count and moisture-content readings for a liquid-limit flow curve, and a sieve table tracking retained mass and percent passing from coarse to fine sizes. The challenge was less about volume than about keeping units, transforms, and data lineage clear.

02 / My role

Code the flow curve and reconcile the tabular checks.

I authored the saved MATLAB liquid-limit script and used the course laboratory workbook as the companion gradation record. My contribution covered the data inputs, semilog plot, fitted relationship, axis treatment, and review of the sieve calculations.

Evidence boundary. The saved files support the workflow and authorship of the MATLAB code. A final reported liquid limit and soil classification are not shown because the available archive does not preserve a reconciled final submission.

03 / What I did

Made each transformation inspectable.

  • Entered paired blow-count and moisture-content observations and checked their ordering before fitting.
  • Used a logarithmic blow-count axis and a first-order fit in transformed space to create the liquid-limit flow curve.
  • Defined axis limits and tick labels explicitly so the chart read like the underlying geotechnical convention.
  • Reviewed sieve mass, cumulative retained mass, and percent-passing columns across the standard sieve sequence.

04 / Approach

Small datasets still deserve reproducible analysis.

  1. Preserve raw observations. Keep measured values distinct from fitted or cumulative quantities.
  2. Use the correct transform. Model blow count on the logarithmic scale used by the liquid-limit flow curve.
  3. Check arithmetic independently. Reconcile retained mass, cumulative mass, and percent passing rather than trusting a single formula chain.
  4. Report only resolved results. Separate a verified method from any result that is absent or ambiguous in the surviving course record.

05 / Outcome

A reusable analysis pattern.

The project produced an authored MATLAB routine for the flow curve and a traceable sieve-analysis workbook. More importantly, it reinforced a durable habit: state the transformation, retain the raw inputs, and make final classification claims only when the full record supports them.
